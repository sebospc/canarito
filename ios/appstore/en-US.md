## Description [4000]
Canarito brings Android Earthquake Alerts to your iPhone.

It is part of an open source project. Someone runs a Canarito server (it can be you, or a friend or relative). The server has one or more receptors: Android emulators at a fixed place that receive Google's alerts. When an alert arrives, the server sends it to your iPhone and it sounds.

How to use it
1. On the server's computer run canarito.py pair. A QR code appears.
2. Open Canarito, scan the QR and confirm the server's name.
3. Allow notifications and location "Always".

What the app does
- Shows whether you are covered, whether your area has no coverage, or whether your server cannot be reached.
- Sounds and shows an alert screen when there is an earthquake, with the safety position from Colombia's UNGRD guide.
- Sends your server your position rounded to 1 km when you move, so the receptor is where you are.
- Tells you when something fails, so silence is not mistaken for safety.

Privacy
- No accounts, no email, no ads, no analytics.
- Your exact position never leaves the iPhone. Only a position rounded to 1 km is sent, and only to the server you linked.
- Whoever runs the server is responsible for what that server stores.
- Alerts go through an open relay that only passes the alert to Apple and stores nothing.

Important
Canarito is not an official system. Alerts can arrive late, not arrive, or arrive without an earthquake. If you feel an earthquake, protect yourself even if nothing sounds.

You need a Canarito server. Code and instructions are at github.com/sebospc/canarito.
